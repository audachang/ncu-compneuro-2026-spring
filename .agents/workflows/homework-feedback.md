# Homework Feedback Writing Guidelines

## Language Style
- **Use neutral, objective language.** Avoid subjective intensifiers such as:
  - ❌ 非常、相當、很、特別、極
  - ❌ 很好、非常出色、特別值得讚賞、展現了企圖心
- **Instead, use factual descriptions or comparative statements:**
  - ✅ 「選題適切」 instead of 「選題很好」
  - ✅ 「涵蓋面廣」 instead of 「非常出色」
  - ✅ 「這一點是其他同學未涉及的」 instead of 「特別值得讚賞」
  - ✅ 「屬有挑戰性的選題」 instead of 「展現了企圖心」
  - ✅ 「結構整齊」 instead of 「結構非常整齊」
  - ✅ 「內容量和分析面向最多」 instead of 「展現了最高的深度和完整度」
- When noting strengths, state observable facts (e.g., "有實際下載原始檔案", "有指出資料的限制") rather than value judgments.

## Structure
- For each student, organize feedback by question (Q3, Q4, etc.)
- Each question should have **優點** and **建議** sections
- End with a comparative summary table if there are multiple students

## Content Approach
- Point out specific, actionable improvements
- Reference concrete details from the student's submission to show the feedback is personalized
- When suggesting improvements, explain *why* the improvement matters (e.g., "加入具體細節會讓介紹更具說服力")
