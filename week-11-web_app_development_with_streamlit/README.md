# Week 11: Web App Development with Streamlit

## Learning Objectives
- Build an interactive web app with Streamlit
- Use widgets, charts, and file upload
- Deploy to Streamlit Cloud

## Topics
1. `st.title()`, `st.write()`, `st.dataframe()`
2. Widgets: `st.slider()`, `st.selectbox()`, `st.file_uploader()`
3. Charts: `st.line_chart()`, `st.pyplot()`
4. Layout: `st.columns()`, `st.sidebar`
5. `@st.cache_data` for performance
6. Deploy to Streamlit Cloud

## Assignment
Build a working Streamlit prototype for your final project. Deploy to Streamlit Cloud.
