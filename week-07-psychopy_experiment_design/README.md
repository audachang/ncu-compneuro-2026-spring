# Week 07: PsychoPy Experiment Design

## Learning Objectives
- Build a complete trial loop for a cognitive experiment
- Record responses and reaction times
- Save data to CSV
- Prepare your experiment for Pavlovia

## Topics
1. Experiment structure: welcome → practice → main → debrief
2. Trial loop: shuffle conditions, show stimulus, record RT
3. Saving data with pandas
4. Participant info dialog: `gui.DlgFromDict`
5. Pavlovia upload checklist

## Assignment
Finalize your experiment for Week 8 Pavlovia upload.
