# Week 03: Data Structures & File I/O

## Learning Objectives
- Use Python's core data structures: lists, dicts, tuples, sets
- Read and write text and CSV files
- Organize behavioral data into dictionaries

## Topics
1. Lists: indexing, slicing, `append`, `sort`, `pop`
2. Dicts: key-value pairs, `.get()`, `.items()`
3. Tuples: immutable sequences, unpacking
4. Sets: unique elements, union/intersection
5. `open()` — read/write text files
6. `csv` module

## Assignment
Complete `week-03-starter.ipynb`. Focus on the CSV parsing exercise.
