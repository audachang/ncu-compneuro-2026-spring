# Week 08: Midterm — Online Experiment on Pavlovia

## MILESTONE: Deploy a Cognitive Experiment Online

This week you will:
1. Upload your PsychoPy experiment to Pavlovia
2. Run a live demo with classmates as participants
3. Download data and give a 5-minute analysis presentation

## Deliverables
- Working experiment URL (Pavlovia "Running" state)
- Data from at least 5 participants
- 5-minute presentation: design, Pavlovia screenshot, 2–3 plots

## Pavlovia Upload Checklist
- [ ] Experiment runs locally without errors
- [ ] Only Pavlovia-compatible components used
- [ ] GitLab repo created on Pavlovia dashboard
- [ ] Experiment set to "Running"
- [ ] Pilot URL tested in Chrome/Firefox

## Grading
| Criterion | Points |
|-----------|--------|
| Experiment works online | 40 |
| Data collected correctly | 25 |
| Analysis with 2+ plots | 25 |
| Presentation clarity | 10 |
