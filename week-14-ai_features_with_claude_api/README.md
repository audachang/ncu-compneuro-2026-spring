# Week 14: AI Features with the Claude API

## Learning Objectives
- Call Claude using the Anthropic Python SDK
- Add a natural language analysis feature to your app
- Manage API keys safely
- Design responsible, bounded AI features

## Topics
1. `pip install anthropic`
2. `client.messages.create()`
3. System prompts and user messages
4. `st.chat_message()`, `st.chat_input()` in Streamlit
5. `.env` and `st.secrets` for key management
6. Responsible AI: disclaimers, limits

## Assignment
Integrate at least one Claude API feature into your final project app.
