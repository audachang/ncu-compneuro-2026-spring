# Week 09 作業：與 AI 協作的三階段資料分析練習

**課程**：電腦硬體與程式語言在行為科學實驗與大數據分析之應用
**學期**：2026 Spring
**主題**：人機協作光譜（Human–AI Collaboration Spectrum）— 從完全自主到完全口語委派
**附件**：`data_gov_tw_health_5star_datasets.xlsx`（data.gov.tw 健康類五星金牌資料集，共 2,153 筆，3 個生命歷程分類，欄位含機關、檔案格式、更新頻率、下載連結等）

---

## 一、學習目標

本作業旨在讓同學體驗「與生成式 AI 協作做資料分析」的三種典型工作模式，並反思各模式下：

1. 人類所需投入的認知負荷
2. 對最終成果的掌控度與責任歸屬
3. AI 補位（augmentation）vs. 取代（automation）的界線
4. 在科學研究情境下，何種模式較能維護方法學嚴謹性與可重現性

修畢本作業後，同學應能說明在自己的研究流程中，哪些環節適合用哪一種協作模式，以及為何如此判斷。

## 二、三階段任務說明

附件 Excel 檔包含 data.gov.tw 經官方品質檢測獲得「金」等級（最高）的健康類資料集清單。請以這份資料集本身為素材，依下列三階段順序完成作業。**三個階段的研究問題不必相同**，但合理情況下應彼此相關（例如同一主軸的不同切面）。

### 階段一：完全自主規劃（Human-only Planning）

**情境**：你是一位想找題目的研究者，AI 完全離線。

**任務**：
1. 不使用任何 AI 工具，人工檢視附件 Excel 的兩個工作表（「五星健康類資料集」與「摘要統計」）。
2. 從中**自行**辨認一個值得探究的研究問題或資料分析目標。例：
   - 「衛福部不同單位的開放資料更新頻率是否與資料筆數相關？」
   - 「老年安養類資料集的提供機關地理分布是否反映人口高齡化趨勢？」
   - 「健保署金牌資料集的檔案格式是否較其他機關更傾向結構化？」
3. 撰寫一份**執行計畫文字檔**（`stage1_plan.md` 或 `stage1_plan.txt`），須包含：
   - **研究問題**（一句話陳述）
   - **資料前處理步驟**（至少 3 步）
   - **分析方法**（至少 1 個進階分析：NLP / 聚類 / 時間序列 / 網絡分析 / 統計檢定 等）
   - **預期視覺化**（至少 1 張圖的形式描述）
   - **預期結論的形式**（你打算用什麼樣的證據支持結論？）
   - **預估所需時間**（以小時為單位）

**繳交格式**：純文字檔（`.md` 或 `.txt`），約 400–800 字。

**禁止**：在本階段使用任何 LLM 工具（含翻譯）。可以用搜尋引擎查找方法學名詞。

---

### 階段二：AI 修訂計畫（AI-assisted Refinement）

**情境**：你已有初稿，請 AI 擔任資深研究助理協助打磨。

**任務**：
1. 將階段一的 `stage1_plan.md` 完整提供給 Claude（或其他 LLM），請 AI **修訂**你的計畫。
2. 在你的提示詞中明確要求 AI：
   - 指出計畫中的方法學弱點
   - 提出至少 2 個替代分析方法並比較利弊
   - 提醒可能的資料偏差或詮釋陷阱（如 selection bias、生態謬誤）
   - 補充相關的統計假設檢驗或 reproducibility 考量
3. 與 AI 進行**至少 2 輪對話**（你給回饋後讓 AI 再修一次）。
4. 最終輸出**修訂後計畫**（`stage2_plan_revised.md`），並在文末附上 1 段反思（150–300 字）：
   - AI 提出哪些你沒想到的觀點？
   - 你接受了哪些建議、否決了哪些建議、原因為何？
   - 修訂後的計畫在哪些面向變得更強？

**繳交格式**：
- `stage2_plan_revised.md`（修訂後計畫 + 反思）
- `stage2_dialogue.docx` 或 `stage2_dialogue.md`（完整 AI 對話紀錄，截圖或匯出皆可）

**評分重點**：對話的批判性與來回深度，而非 AI 回答本身的長度。

---

### 階段三：純口語委派（Voice-only Delegation）

**情境**：你只是一位有想法的領域專家，分析全交給 AI。

**任務**：
1. 不需自己寫計畫。
2. 用**模擬口語**的純文字（200 字以內）向 Claude 描述一個目標，例如：

   > 「我想知道這份金牌健康資料裡，最常被衛福部更新的資料集是哪些；還有，這些資料集如果拿來教學生做時間序列分析，哪幾個最適合？幫我看一下，最後給我一個排序好的清單。」

3. 把這段口語丟給 Claude，請它：
   - 自己解析目標、規劃步驟
   - 自動執行（讀取附件 Excel、跑分析、產出結果）
   - 輸出最終結果（圖表、摘要、推薦清單）
4. 你只能再追問**最多 3 個澄清問題**，不可手動修改 AI 寫的程式碼或計畫。
5. 最後撰寫一段**評估報告**（`stage3_evaluation.md`，300–500 字）：
   - AI 對你「口語意圖」的解讀是否到位？
   - 它的執行步驟你是否同意？是否有跳過必要的驗證？
   - 若以這份成果直接寫進論文，你會有哪些疑慮？

**繳交格式**：
- `stage3_oral_brief.txt`（你給 AI 的那段口語化敘述）
- `stage3_dialogue.docx`（完整 AI 對話與輸出）
- `stage3_evaluation.md`（評估報告）
- 所有 AI 產出的圖表、表格檔案（保留原檔名）

完成三階段後，撰寫一份**綜合反思**（`final_reflection.md`，500–800 字），對照三階段在以下面向的差異：

| 比較面向                           | 階段一 | 階段二 | 階段三 |
| ---------------------------------- | ------ | ------ | ------ |
| 你的認知投入時間                   |        |        |        |
| 你對成果的掌控感 (1–5)             |        |        |        |
| 成果的方法學嚴謹度（自評）         |        |        |        |
