# Homework-week09

## Stage 1: Human-only Planning
### **研究問題**

- 不同資料**提供機關**(或行程區域)，在不同的**生命歷程分類**上，**資料筆數**的分佈情況，隨著時間（**首次發佈日**）的演變

### **資料前處理步驟**（至少 3 步）
- **Data cleansing**: 檢查遺失值和異常值，去除有遺失值的資料列，以中位數取代異常值
- **Exploratory data analysis**: 檢視各欄位token、以pivot table 檢查資料分佈、 
- **data recoding**: 
    - **首次發佈日** --> recode多出一欄 
    - **首次發佈季**；如此同一時間點有更多資料可累積分析；
    - **提供行政區域**：單一行政單位不易作有趣、有意義的推論，彙整出各行政區域特性供比較

### **分析方法**（至少 1 個進階分析：NLP / 聚類 / 時間序列 / 網絡分析 / 統計檢定 等）
- **依變項**：**資料筆數**
- **獨變項**：時間（**首次發佈季**）、**提供行政區域**、**生命歷程分類**
- **分析方法**：**Statistical analysis**: Time series comparisons, Survival analsys

### **預期視覺化**（至少 1 張圖的形式描述）
- **line graph**: y-axis --> **資料筆數**, x-axis --> **首次發佈季**；color --> **提供機關行政區域**
  - 以不同顏色折線呈現各行政區的資料量隨時間的變化
- **geograph**: 各行政區資料總量比較

  - 六都的資料總量較多
  - 六都的資料更新週期較短
- 越接近現在，資料年增量越多
