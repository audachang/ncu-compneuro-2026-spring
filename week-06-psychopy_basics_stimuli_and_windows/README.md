# Week 06: PsychoPy Basics — Stimuli & Windows

## Learning Objectives
- Install PsychoPy and create a display Window
- Draw visual stimuli (text, shapes, images)
- Control timing with clocks
- Capture keyboard input

## Topics
1. `pip install psychopy` or standalone installer
2. `visual.Window`, `visual.TextStim`, `visual.Rect`, `visual.Circle`
3. `core.Clock`, `core.wait()`
4. `event.getKeys()`, `event.waitKeys()`
5. Draw-flip loop: `stimulus.draw()` → `win.flip()`

## Assignment
Complete `week-06-starter.ipynb`. Build the attention cue + target display.
