# Week 10: Agentic Workflows & GitHub

## Learning Objectives
- Use Claude Code for multi-step coding tasks
- Commit and push code with git via Claude Code
- Set up a GitHub Actions CI workflow
- Write tests with pytest

## Topics
1. Multi-step agentic tasks
2. Git workflow: branch, commit, PR
3. GitHub Actions: `.github/workflows/test.yml`
4. Writing tests with `pytest`
5. Code review workflow

## Assignment
Add pytest tests to your project and set up a GitHub Actions workflow.
