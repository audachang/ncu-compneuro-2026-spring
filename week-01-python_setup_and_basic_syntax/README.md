# Week 01: Python Setup & Basic Syntax

## Learning Objectives
- Install Anaconda, VS Code, and Jupyter
- Create and activate a conda environment
- Understand Python variables, data types, and operators
- Write and run your first Python programs in a Jupyter notebook

## Topics
1. Installing Anaconda and VS Code
2. `conda create -n compneuro python=3.10`
3. Jupyter notebook interface — cells, kernel, shortcuts
4. Variables and assignment
5. Data types: `int`, `float`, `str`, `bool`
6. Arithmetic and comparison operators
7. `print()` and f-strings
8. `import antigravity` Easter egg

## Tools
- [Anaconda](https://www.anaconda.com/download)
- [VS Code](https://code.visualstudio.com/)
- JupyterLab
