# Week 05: Data Visualization with Matplotlib

## Learning Objectives
- Create line, scatter, bar, and histogram plots
- Use subplots for multi-panel figures
- Add labels, legends, and annotations
- Visualize cognitive data effectively

## Topics
1. `plt.plot()`, `plt.scatter()`, `plt.bar()`, `plt.hist()`
2. `plt.subplots()` — multi-panel figures
3. Labels: `xlabel`, `ylabel`, `title`, `legend`
4. Reference lines: `axvline`, `axhline`
5. Annotations: `plt.annotate()`
6. `plt.savefig()`
