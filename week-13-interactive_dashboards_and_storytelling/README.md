# Week 13: Interactive Dashboards & Data Storytelling

## Learning Objectives
- Create interactive charts with Plotly Express
- Add annotations to tell a data story
- Embed interactive charts in Streamlit
- Apply principles of clear data visualization

## Topics
1. Plotly Express: `px.bar()`, `px.scatter()`, `px.line()`
2. Hover labels, color scales, annotations
3. Altair basics
4. Embedding in Streamlit: `st.plotly_chart()`

## Assignment
Add 2+ interactive Plotly charts to your Streamlit app with annotations.
