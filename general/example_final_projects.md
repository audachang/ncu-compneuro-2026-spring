# 期末專案範例：三個分析方向
## Example Final Projects: 3 Analytical Goal Options

> **課程**: NS5116 Part 2 (Weeks 9–16) — Vibe Coding & Agentic Programming  
> **最終目標**: 使用台灣政府開放資料，以 Streamlit 建置互動式 Web App  
> **資料來源**: [政府資料開放平臺 (data.gov.tw)](https://data.gov.tw/)

---

## Option 1 ☁️ 空氣品質與生活行為決策儀表板

**Air Quality & Behavioral Decision-Making Dashboard**

### 資料集
| 資料集名稱                                              | 來源   | 格式     |
| ------------------------------------------------------- | ------ | -------- |
| [空氣品質指標 (AQI)](https://data.gov.tw/dataset/40448) | 環境部 | JSON API |
| [紫外線即時監測](https://data.gov.tw/dataset/6076)      | 環境部 | JSON API |

### 分析目標

探討**環境因子如何影響人的日常行為決策**。透過即時與歷史 AQI 資料，建立一個互動儀表板回答以下問題：

1. **地理差異**: 台灣各縣市空氣品質差異有多大？哪些區域長期處於不健康等級？
2. **時間模式**: AQI 是否有明顯的週期性（日內、週間 vs 週末、季節）？
3. **行為建議引擎**: 結合 Claude API，根據當前 AQI 自動產生「是否適合戶外運動」的個人化建議

### 技術堆疊對應 (Weeks 9–16)

| 週次    | 課程主題         | 專案進度                           |
| ------- | ---------------- | ---------------------------------- |
| Week 09 | Vibe Coding 入門 | 用 Claude Code 搭建基本專案架構    |
| Week 10 | GitHub 工作流    | 版本控制與自動化                   |
| Week 11 | Streamlit 開發   | 建立互動式地圖與時間序列圖表       |
| Week 12 | Open Data API    | 串接環境部 AQI 即時 API            |
| Week 13 | 互動儀表板       | 用 Plotly 繪製動態空品地圖與趨勢圖 |
| Week 14 | Claude API       | 加入 AI 行為建議功能               |
| Week 15 | 工作坊           | UI 美化、peer review、文件撰寫     |
| Week 16 | 發表             | 線上 Demo                          |

### 行為科學連結
- **風險知覺 (Risk Perception)**: 人們如何根據空氣品質資訊調整行為？
- **環境心理學**: 空汙對情緒與認知的潛在影響

## Option 2 🚗 道路交通事故風險視覺化與認知因素分析

**Traffic Accident Risk Visualization & Cognitive Factor Analysis**

### 資料集
| 資料集名稱                                            | 來源         | 格式 |
| ----------------------------------------------------- | ------------ | ---- |
| [道路交通事故資料](https://data.gov.tw/dataset/12197) | 內政部警政署 | CSV  |
| [各縣市人口統計](https://data.gov.tw/dataset/8411)    | 內政部戶政司 | CSV  |

### 分析目標

以交通事故開放資料為基礎，建構一個探索**人因 (human factors) 在交通安全中的角色**的互動式 Web App：

1. **人口學風險剖面**: 不同年齡層、性別的事故率是否有顯著差異？老年駕駛的風險模式？
2. **時間與注意力**: 事故是否集中在特定時段（如通勤尖峰、深夜疲勞駕駛）？這與注意力的晝夜節律有何關聯？
3. **AI 風險摘要**: 使用 Claude API 自動製作「每月交通安全快報」，將統計數據轉化為易懂的故事敘述

### 技術堆疊對應 (Weeks 9–16)

| 週次    | 課程主題         | 專案進度                                |
| ------- | ---------------- | --------------------------------------- |
| Week 09 | Vibe Coding 入門 | 用 Claude Code 建立 repo 與資料下載腳本 |
| Week 10 | GitHub 工作流    | CI/CD 自動更新資料                      |
| Week 11 | Streamlit 開發   | 事故熱點地圖與篩選介面                  |
| Week 12 | Open Data API    | 串接警政署 CSV + 人口資料               |
| Week 13 | 互動儀表板       | 年齡×時間交叉分析互動圖表               |
| Week 14 | Claude API       | AI 自動產生每月交通安全快報             |
| Week 15 | 工作坊           | 優化使用者體驗、新增篩選條件            |
| Week 16 | 發表             | 線上 Demo                               |

### 行為科學連結
- **注意力與警覺性 (Attention & Vigilance)**: 疲勞駕駛、分心駕駛的認知神經科學基礎
- **老化與認知衰退**: 年齡相關的反應時間下降如何反映在事故統計中?

## Option 3 👶 台灣人口變遷與世代發展敘事

**Taiwan Demographic Transition & Generational Development Narrative**

### 資料集
| 資料集名稱                                                | 來源         | 格式 |
| --------------------------------------------------------- | ------------ | ---- |
| [出生數統計](https://data.gov.tw/dataset/8409)            | 內政部戶政司 | CSV  |
| [結婚對數統計](https://data.gov.tw/dataset/32962)         | 內政部戶政司 | CSV  |
| [各級學校概況 (學生數)](https://data.gov.tw/dataset/6250) | 教育部       | CSV  |

### 分析目標

結合多個人口與教育資料集，以資料敘事 (data storytelling) 的手法呈現台灣的**少子化議題與世代心理**：

1. **少子化時間軸**: 過去 30 年出生率、結婚率的趨勢變化——下降的轉折點在哪裡？
2. **區域差異**: 六都 vs. 非六都的人口結構差異如何反映不同的生活決策？
3. **AI 敘事生成**: 利用 Claude API，讓使用者選擇一個縣市後，自動生成一段「這個城市的世代故事」，結合數據與心理學洞察

### 技術堆疊對應 (Weeks 9–16)

| 週次    | 課程主題         | 專案進度                             |
| ------- | ---------------- | ------------------------------------ |
| Week 09 | Vibe Coding 入門 | 用 Claude Code 快速清理多個 CSV 資料 |
| Week 10 | GitHub 工作流    | 建立 data pipeline、版本控制         |
| Week 11 | Streamlit 開發   | 時間軸動畫與縣市選擇器 UI            |
| Week 12 | Open Data API    | 整合戶政司 + 教育部多來源資料        |
| Week 13 | 互動儀表板       | 人口金字塔動畫、趨勢對比圖           |
| Week 14 | Claude API       | AI 世代故事生成器                    |
| Week 15 | 工作坊           | Peer review、文件撰寫                |
| Week 16 | 發表             | 線上 Demo                            |

### 行為科學連結
- **發展心理學 (Developmental Psychology)**: 少子化如何改變兒童的社會化經驗？
- **決策心理學**: 生育決策背後的認知與情緒因素
