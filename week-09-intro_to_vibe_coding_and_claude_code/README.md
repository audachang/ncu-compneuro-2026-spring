# Week 09: Intro to Vibe Coding & Claude Code

## Learning Objectives
- Understand what "vibe coding" and agentic programming mean
- Install and configure Claude Code CLI
- Write effective prompts to generate working code
- Scaffold a new project using Claude Code

## Topics
1. Vibe coding vs. autocomplete AI
2. Claude Code CLI: installation and authentication
3. Effective prompting strategies
4. Iterative refinement: describe → generate → test → revise
5. Project scaffolding with Claude Code
6. Limits and risks: verifying AI output

## Tools
- [Claude Code CLI](https://docs.anthropic.com/en/docs/claude-code)
- Terminal / bash

## Assignment
Use Claude Code to scaffold your final project directory. Commit to GitHub.
