# Week 8: Other CUDA Python Libraries

In addition to CuPy, there are several other Python libraries that you can use to leverage the power of CUDA and GPUs. In this section, we'll take a brief look at a few of these libraries.

## Numba

Numba is a just-in-time compiler for Python that translates a subset of Python and NumPy code into fast machine code. Numba can also be used to compile Python code for the GPU.

## PyCUDA

PyCUDA is a Python wrapper for NVIDIA's CUDA API. It allows you to access the CUDA API from within Python, which gives you more control over how you use the GPU.

## RAPIDS

RAPIDS is a suite of open-source software libraries and APIs for executing end-to-end data science and analytics pipelines entirely on GPUs. RAPIDS is built on top of CUDA and is designed to be easy to use for data scientists who are already familiar with Python and the PyData stack.
