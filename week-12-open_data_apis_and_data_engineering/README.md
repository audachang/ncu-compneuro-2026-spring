# Week 12: Open Data APIs & Data Engineering

## Learning Objectives
- Find datasets on Taiwan's open data portal (data.gov.tw)
- Make HTTP API calls with `requests`
- Clean data with pandas
- Handle missing values and type issues

## Topics
1. REST basics: GET, JSON responses
2. `requests.get()`, `.json()`, `.status_code`
3. data.gov.tw and EPA open data
4. pandas: `dropna()`, `fillna()`, `astype()`, `to_datetime()`
5. Merging datasets: `pd.merge()`

## Assignment
Find a dataset on data.gov.tw for your final project. Clean it and show summary + one plot.
